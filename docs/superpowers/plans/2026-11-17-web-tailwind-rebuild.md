# Web UI Tailwind Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every web page looks like the user's mockup, built from one Tailwind-generated stylesheet, a 240px sidebar and Phosphor icons.

**Architecture:** A repo-root `web-ui/` npm project holds Tailwind v4 and Phosphor. `npm run build` writes two committed files into the app assets: `shared/ui.css` (mockup tokens, `ui-` components, `tw:` utilities) and `shared/ph-icons.js` (inline SVG sprite). Pages move to the new classes one batch at a time; old CSS is deleted at the end.

**Tech Stack:** Tailwind CSS v4 (`tailwindcss`, `@tailwindcss/cli`), `@phosphor-icons/core`, Node 24 (dev machine only), plain HTML/JS pages, JUnit asset tests (`./gradlew :app:testDebugUnitTest`).

**Spec:** `docs/superpowers/specs/2026-11-17-web-tailwind-rebuild-design.md` (mockup: `docs/superpowers/specs/2026-11-16-web-theme-mockup.html`)

## Global Constraints

- Mockup `<style>` values are exact: colours, radii (7/12/16px), sizes, weights, breakpoints (1500/1150/850/540/360px); "Usability refinement" rules override earlier ones.
- Sidebar: `--sidebar-width: 240px`; `200px` at `(max-width: 1150px)`; `72px` at `(max-width: 850px)`; bottom bar at `(max-width: 540px)`.
- Tailwind prefix `tw` (`@import "tailwindcss/utilities.css" layer(utilities) prefix(tw)`); components prefixed `ui-`; no preflight until Task 13.
- No runtime network loads: no CDN, no remote fonts, no `http(s)://` in `ui.css` or `ph-icons.js`.
- Dependencies pinned to exact versions (no `^`/`~`) with `web-ui/package-lock.json` committed.
- Hex colours only inside custom-property definitions (existing `TokenOnlyColoursAssetTest` rule).
- Every element `id` a page's scripts use survives its migration.
- Never touch `verifyFastCam`/checksums, toolchain versions, signing, jniLibs; debug APK only.
- Theme switch is `data-theme="light|dark"` on `<html>` (set by `shared/theme.js`); dark tokens key off `:root[data-theme=dark]`.
- Built files start with the banner `/* Generated by web-ui — do not edit. Run: cd web-ui && npm run build */`.
- Test command form: `./gradlew :app:testDebugUnitTest --tests '*<Name>' --console=plain`. Known Windows baseline: 19 failures (`.superpowers/sdd/2026-11-16-web-theme-redesign/baseline-failures.txt`).

## Review Focus

- **Native app WebView (`data-android-embed="1"`)**: shell chrome stays hidden; pages still lay out at car-screen width with no sidebar gap → Task 4 test `embeddedHidesShellChrome`.
- **Unmigrated page next to migrated ones**: a page still on old CSS must look unchanged after `ui.css` ships (no preflight, prefixed classes) → Task 1 test `noPreflightWhileMigrating`.
- **Script-built markup**: HTML that page scripts build at runtime (`shared/*.js`) must use `ui-` classes too, or lists render unstyled → Task 6 test `pageScriptsUseNoLegacyClasses`.
- **RTL (Hebrew)**: sidebar edge and row icons mirror → Task 4 test `shellUsesLogicalProperties` (kept, updated).
- **Stale build**: someone edits `web-ui/src` but forgets to rebuild → Task 1 `npm run check` fails; run in Task 14.
