Partial diagnostic coverage

Reads the warning lamps the instrument cluster shows, plus the TPMS, 12V battery and charging indicators. It does not read stored ECU diagnostic trouble codes (DTCs), and it does not send CAN/UDS commands, clear faults, reset modules or change vehicle settings.
