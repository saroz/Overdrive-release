Tyre pressure limits

Set the normal pressure range for each axle. A tyre below the minimum or above the maximum raises a warning; below the critical value it raises a deflated-tyre alert. Used for push and Telegram notifications and for the corner colours in Vehicle Control. Defaults suit stock tyres — change them if your placard pressures differ.

Push delivery

Enables alerts on the device you are currently using. Each phone you install the dashboard onto needs to be enabled here once.

Push notifications require Zrok or a reverse proxy. Cloudflare quick tunnels change every restart and would invalidate every subscription. Tailscale serves over plain HTTP and can't be used for Web Push unless using a reverse proxy. Open the dashboard from your reserved Zrok or reverse proxy URL on your phone, Add to Home Screen, then return here to enable.

Minimum importance

A device-wide floor applied on top of the categories above. Raise it to silence lower-importance pushes in one place — e.g. "Warn and up" drops every Notice/Info push (routine surveillance, charging started/stopped) while keeping Alerts and Criticals. Off tiers are still recorded in the log.
